# openGym Tounsi for Android

Non-commercial Tunisian edition of [openGym](https://github.com/DuarteSantos8/openGym).
Requires Android 7 or later. This is a debug-signed build for direct installation.

- [Download the APK](https://github.com/Ibrahimmed96/opengym-tounsi-android/releases/download/v1.4.3-tounsi-android/openGym-tounsi-android.apk)
- [Download the corresponding source and build instructions](https://github.com/Ibrahimmed96/opengym-tounsi-android/releases/download/v1.4.3-tounsi-android/openGym-tounsi-android-source.tar.gz)

The AI voice coach opens the hosted site in a browser and requires authorized access.
The source archive includes the AGPL license and the separate exercise media notice.
